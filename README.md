
# Posonas

Plataforma web comunitaria LGBTQ+ desarrollada con Astro, Tailwind CSS y TypeScript.

## Descripción

Posonas es un proyecto de desarrollo web orientado a crear un espacio digital inclusivo donde las personas puedan conectar, expresarse y participar en actividades comunitarias.

Actualmente se encuentra en su primera etapa de desarrollo.

## Tecnologías

- Astro 7
- Tailwind CSS 4
- TypeScript
- HTML5
- CSS3
- Git y GitHub

## Estructura del proyecto

```text
src/

├── layouts/

├── pages/

```

## Instalación

Requisitos:
- Node.js 24 o una versión compatible con Astro
- npm

Clonar el repositorio:

```bash
git clone https://github.com/criti981298/posonas.posonas.git
```

Entrar al proyecto:

```bash
cd posonas.posonas
```

Instalar dependencias:

```bash
npm install
```

Iniciar el servidor:

```bash
npm run dev
```

En Windows PowerShell, si la política de ejecución bloquea npm.ps1, utilizar:

```powershell
npm.cmd run dev
```

Abrir en el navegador:

http://localhost:4321/
